# HTTP Requests

A basic Node.js project demonstrating **how HTTP requests are handled** using Express.js.

## Concepts Covered

* HTTP Requests
* GET Requests
* POST Requests
* Request and Response Handling
* Express.js Routing
* Middleware

## Technologies Used

* Node.js
* Express.js
* JavaScript

## How to Run

1. Clone the repository.
2. Install the dependencies:

```bash
npm install
```

3. Start the server:

```bash
node index.js
```

4. Open the application or use an API client such as Postman to test the requests.

## Purpose

This project was created to understand **HTTP request methods, Express.js routing, and how servers handle client requests and responses**.
